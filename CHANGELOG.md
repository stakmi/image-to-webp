## 0.1.0 — unreleased

- First release as a Python library (`import image_to_webp`).
- Python API: `convert_file`, `convert_bytes`, `convert_image`, `convert_many`.
- `image-to-webp` command (also `python -m image_to_webp`).
- Optional installs for more formats: `[heif]`, `[raw]`, `[svg]`, `[all]`.
